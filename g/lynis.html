Preparación del sistema a auditar

Instalación

En el equipo donde se vaya a realizar el análisis hay que ejecutar los siguientes pasos.

Primero hay que descargar la clave pública del repositorio y pasarla a formato GPG:

curl -fsSL https://packages.cisofy.com/keys/cisofy-software-public.key | sudo gpg --dearmor -o /usr/share/keyrings/cisofy-software-public.gpg

Luego hay que crear un nuevo fichero /etc/apt/sources.list.d/cisofy-lynis.sources y añadir el siguiente contenido en el:

X-Repolib-Name: CISOfy Lynis Repository
Types: deb
URIs: https://packages.cisofy.com/community/lynis/deb/
Suites: stable
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/cisofy-software-public.gpg

Por último hay que actualizar la lista de paquetes e instalar el paquete lynis:

apt-get update
apt-get install -y lynis

Comprobación

Para comprobar que la instalación se realizó correctamente se puede ejecutar el siguiente comando para ver la versión del paquete lynis:

lynis --version

Auditorias

Como auditar el sistema local

El comando mínimo de auditoria es el siguiente:

lynis audit system (Otros_parámetros)
Otros parámetros: 
--report-file [Ruta_reporte]
 Al acabar la auditoría generará un fichero de reporte en la ruta indicada. No tendrá el mismo formato que la salida del propio comando. 
 | tee [Ruta_salida]
 Redirige la salida exacta del comando (incluyendo los colores) a un fichero.

Cada advertencia o sugerencia tiene un código de error como, por ejemplo: FINT-4350. Puedes ver en la página oficial de Lynis la descripción de cada código junto a una sugerencia de como arreglarlo: 

https://cisofy.com/lynis/controls/[Código_lynis]/
