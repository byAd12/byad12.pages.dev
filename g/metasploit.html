Comandos básicos

Antes de ejecutar Metasploit se puede saber con Nmap los servicios y sus versiones de la máquina a atacar:

nmap -sV --top-ports 1000 [Máquina_a_atacar]

Con esta información se puede buscar en la web de cve.org cada servicio y versión para poder averiguar si hay alguna versión vulnerable.

Para iniciar una consola interactiva de Metasploit hay que ejecutar:

msfconsole

Dentro de la consola se pueden buscar scripts como escaneos de puerto, servicios específicos, etc:

search [Búsqueda]

Para usar un script que se haya encontrado con el comando search solo hay que indicar el número que tiene asignado en la lista de búsqueda o también se puede indicar directamente el nombre del script como por ejemplo auxiliary(scanner/portscan/tcp), que es un escaneo de puertos TCP:

use [Número_search/Nombre_script]

Una vez se tenga el script seleccionado se pueden ver los parámetros disponibles. Se dividen en "Module options" (parámetros de la máquina remota) y "Payload" (código a ejecutar si se puede contactar con la máquina remota):

show options

Algunos parámetros importantes pueden ser:

RHOSTS
 IP del equipo o lista de equipos remotos a los que se aplicará el script. 
LHOSTS
 IP del equipo que se utiliza para crear una conexión inversa hacia RHOST una vez el ataque tenga éxito. 
LPORT
 El puerto que se utilizará para crear una conexión inversa hacia RHOST una vez el ataque tenga éxito.

Para asignar un nuevo valor a un parámetro se debe usar el comando set seguido del nombre del parámetro y el valor a asignar:

set [Nombre_parámetro] [Valor_a_asignar]

Una vez se hayan configurado los parámetros necesarios hay que ejecutar el script con el siguiente comando:

run
