Docker

Build, Ship and Run

none

Imágenes

Descargar una imagen desde el repositorio hub.docker.com sin necesidad de autenticarse:

docker pull [Imagen]:(Versión)

La versión del docker a ejecutar, si no se especifica será la última versión disponible - latest.

Crear un docker sin iniciarlo:

docker create [Imagen]:(Versión)

Ver todas las imágenes descargadas:

docker image ls

Ver solo una imagen descargada específica:

docker image (Imagen)

Eliminar una imagen:

docker image rm (Imagen)

Nota: no debe haber ninún docker creado que esté asociado con la imagen a eliminar.

Inspeccionar una imagen:

docker image inspect (Imagen)

Información de la aplicación

Ver la versión de la aplicación Docker:

docker --version

Ver la versión de Docker con más detalles:

docker version

Ver la información de la aplicación Docker:

docker info

Ver registros

Ver todos los eventos de los dockers:

docker events

Ver los registros de ub docker en tiempo real:

docker logs -f [Nombre_docker]

Inspeccionar el contenido de un docker:

docker inspect --format=(Formato) [Imagen]

--format=(formato): Es opcional. Este es un ejemplo de formato: {{.Id}}.

Crear e iniciar un docker

El comando docker run permite ejecutar un docker existente o crear uno nuevo a partir de una imagen. Una vez creado se iniciará automáticamente: 

docker run (Parámetros) [Imagen] (Comando)

Docker: Puede ser el ID de un docker existente o el nombre de una imagen con la que se creará el docker.
Si esta imagen no se descargó previamente, el sistema descargará la versión latest a no ser que se especifique otra versión.

Parámetros de docker run:

-d
 Ejecuta el docker en segundo plano. 
-v [Ruta_en_sistema_local]:[Ruta_en_docker]
 Persistencia de ficheros - Sirve para eenlazar una carpeta del docker con una carpeta local para que los ficheros no se eliminen al detener el docker. 
-e [Variable_entorno]=[Valor]
 Modifica una variable de entorno (pej. PUID). 
-h [Hostname]
 Especifica el hostname que tendrá el docker internamente. 
--name [Nombre]
 Asigna al docker un nombre para poder identificarlo. 
--restart unless-stopped
 Indica que se quiere ejecutar el docker persistentemente hasta que se detenga manualmente. 
--rm
 Indica que se debe eliminar el docker al finalizar la tarea o cuando se detenga manualmente.

Limitación de recursos:

--cpus [Cantidad_CPUs]
 Limita los núcleos de la CPU que el docker puede utilizar como máximo (número decimal). 
-m [Cantidad_RAM][Unidad]
--memory [Cantidad_RAM][Unidad]
 Ambos parámetros realizan la misma función:
Limita la cantidad de RAM que el docker puede utilizar como máximo. Ejemplos: "512M" (MiB), "1G" (GiB).

Redirección de puertos:

-P
 Se redirecciona automáticamente todos los puertos abiertos que tenga el docker en ejecución y le asigna un puerto libre del host. 
-p [Puerto_local]:[Puerto_docker]
 Se redirecciona el puerto [Puerto_local] del host hacia el puerto [Puerto_docker] del docker. 
-p [IP_local]:[Puerto_local]:[Puerto_docker]
 También se puede especificar la IP del sistema local del host.
Se puede redireccionar varios puertos a la vez, para ello hay que repetir el parámetro -p por cada puerto a redireccionar.

Modo de red:

Modo bridge: Por defecto el docker está en el modo de red bridge.
Tiene IP propia (a partir de la red creada por docker) y permite usar mapeo de puertos. El servidor DNS será el mismo servidor que utiliza el host. 
--network host
 Modo host: Con este parámetro el docker no tendrá IP ni mapeo de puertos, solo será un proceso del host.

Otras configuraciones de red:

--dns=[IP_servidor_DNS]
 Con este parámetro se indica manualmente el servidor DNS para el docker. Para añadir un servidor secundario se debe duplicar este parámetro. 
--add-host=[Nombre_dominio]:[IP]
 Con este parámetro se indica una nuevo registro DNS interno en el fichero /etc/hosts. Para añadir otro registro se debe duplicar este parámetro.

Sobreescribir la tarea principal del docker:

docker run [Imagen] [Comando]
 Si por ejemplo se va a ejecutar un docker nginx, se puede definir que se ejecute otro proceso diferente y cuando finalize, se detendrá el docker.

Abrir una terminal al ejecutar el docker:

docker run -it [Imagen] (bash|sh)
 Con el parámetro -i se mantiene abierta la entrada estándar STDIN para poder enviar comandos al docker. El parámetro -t permite que en ese flujo de datos aparezcan colores y se pueda usar el tabulador.
Con (bash|sh) se sobrescribe la tarea por defecto para forzar la apertura de una consola interactiva bash o sh.

Para abrir la terminal en un docker que ya se está ejecutando, mire la sección "Abrir una terminal en un docker iniciado".

Nota - cualquiera de estas opciones se puede modificar más tarde con el siguiente comando:

docker update [Parámetros] [Nombre/ID_Docker]

Listar los dockers

Para ver los dockers en ejecución:

docker ps

Ver todos los dockers en ejecución y detenidos:

docker ps -a

Los 2 comandos anteriores muestran el ID, nombre, tiempo de ejecución y tiempo de creación de cada docker.

Gestionar la ejecución de un docker

Iniciar un docker:

docker start [Nombre/ID_Docker]

Detener un docker:

docker stop [Nombre/ID_Docker]

Pausar o reanudar un docker:

docker pause [Nombre/ID_Docker]
docker unpause [Nombre/ID_Docker]

Eliminar un docker

Para eliminar un docker primero se debe detener manualmente:

docker stop [Nombre/ID_Docker]
docker rm [Nombre/ID_Docker]

O también se puede forzar la eliminación sin necesidad de detenerlo manualmente:

docker rm -f [Nombre/ID_Docker]

Copiar ficheros entre el host y el docker

Cómo copiar ficheros internos del docker al host:

docker cp [Nombre/ID_Docker]:[Ruta_en_docker] [Ruta_en_sistema_local]

[Nombre/ID_Docker]: Nombre del docker específico que contiene los ficheros a copiar.
[Ruta_en_docker]: Ruta local del docker que contiene los fichero/s a copiar.
[Ruta_en_sistema_local]: Ruta local del host donde se copiarán los ficheros.

Copiar ficheros del host al interior del docker:

docker cp [Ruta_en_sistema_local] [Nombre/ID_Docker]:[Ruta_en_docker]

[Ruta_en_sistema_local]: Ruta local del host que contiene los fichero/s a copiar.
[Nombre/ID_Docker]: Nombre o ID del docker al que se copiarán los ficheros.
[Ruta_en_docker]: Ruta local del docker donde se copiarán los ficheros.

Abrir una terminal en un docker iniciado

En una terminal se debe ejecutar el siguiente comando para iniciar una sesión de terminal en un docker existente e iniciado:

docker exec -it [Nombre/ID_Docker] [bash|sh]

-i: Modo interactivo.
-t: Proporciona una interfaz de línea de comandos.
[Nombre/ID_Docker]: El nombre o ID del docker al que se quiere acceder.
[bash|sh]: Abre una sesión de bash o shell.

Volúmenes

Un volumen permite que los datos de una ruta en el docker permanezcan almacenados en el host incluso despues de que el docker haya sido eliminado.

Ver todos los volúmenes del sistema:

docker volume ls

Crear un nuevo volumen:

docker volume create [Nombre_volumen]

Eliminar un volumen existente:

docker volume rm [Nombre_volumen]

Para montar un volumen existente en un docker se puede hacer de 2 maneras:

docker run -v [Nombre_volumen]:[Ruta_en_docker] [Imagen]
docker run --mount type=volume,src=[Nombre_volumen],dst=[Ruta_en_docker] [Imagen]

Todos lo datos que hayan en src se cargarán automáticamente en dst aunque si el volumen está vacío y dst tiene datos, todos los datos de dst se copiarán en src. Se permite crear datos en el volumen desde el host y el docker a la vez.
Si el volumen no existe, se creará automáticamente.

Los datos del volumen se almacenan localmente en el sistema del host en la ruta: /var/lib/docker/volumes/[Nombre_volumen]/_data.

Redes

Configuración de una red

Ver las redes y de que tipos son para cada docker:

docker network ls

Modificar redes

Crear una red:

docker network create --driver (Tipo_de_red) --subnet (Dirección_red)/(Máscara_CIDR) --gateway (IP_default_gateway) [Nombre_red]

--driver, --subnet y --gateway son opcionales. Creará una interfaz en el host.

--driver: Es el modo de red a seleccionar como bridge, none, host, ...

Eliminar una red tipo bridge:

docker network rm [Nombre_red]

Cambiar un docker existente a la nueva red:

docker run --network [Nombre_red] [Imagen]

Ejemplos

Docker "httpd"

Añadir una página .HTML:

docker run -p 80:80 -p 443:443 -d httpd
docker exec -it [Nombre/ID_Docker] [bash|sh]
apt-get update
apt-get install -y nano

./htdocs/index.html: Editar el fichero para cambiar la página default.

Hay que acceder a la siguiente URL http://[IP]:[Puerto], siendo el puerto el que redirige todo el tráfico hacia el docker (especificado en el parámetro -p).

Docker "heimdall"

Sirve para organizar aplicaciones web en un solo lugar:

docker run --name heimdall -e PUID=1000 -e PGID=1000 -e TZ=america/new_york -p 9998:80 -p 9997:443 -v /home/usuario/Descargas/docker_adr:/config --restart unless-stopped linuxserver/heimdall

Una vez se haya creado el docker se puede acceder a mediante la URL http://localhost:[Puerto]
