Docker

Build, Ship and Run

none

Imágenes

Descargar una imagen desde el repositorio hub.docker.com sin necesidad de autenticarse:

docker pull [imagen]:(tag)

Tag: La versión del docker a ejecutar, si no se especifica será la última versión disponible - latest.

Crear un docker sin iniciarlo:

docker create [imagen]:(tag)

Ver todas las imágenes descargadas:

docker image ls

Ver solo una imagen descargada específica:

docker image (imagen)

Eliminar una imagen:

docker image rm (imagen)

Nota: no debe haber ninún docker creado asociado con esta imagen.

Inspeccionar una imagen:

docker image inspect (imagen)

Información de la aplicación

Ver la versión de la aplicación Docker:

docker --version

Ver la versión de Docker con más detalles:

docker version

Ver la información de la aplicación Docker:

docker info

Ver registros

Ver todos los eventos de los dockers:

docker events

Ver los registros de ub docker en tiempo real:

docker logs -f [nombre_docker]

Inspeccionar el contenido de un docker:

docker inspect --format=(formato) [docker]

--format=(formato): Es opcional. Este es un ejemplo de formato: {{.Id}}.

Crear e iniciar un docker

El comando docker run permite ejecutar un docker existente o crear uno nuevo a partir de una imagen. Una vez creado se iniciará automáticamente: 

docker run (parámetros) [docker]

docker: Puede ser el ID de un docker existente o el nombre de una imagen con la que se creará el docker.
Si esta imagen no se descargó previamente, el sistema descargará la versión latest a no ser que se especifique otra versión.

Parámetros de docker run:

-d
 Ejecuta el docker en segundo plano. 
-v [ruta_en_sistema_local]:[ruta_en_docker]
 Persistencia de archivos - Sirve para eenlazar una carpeta del docker con una carpeta local para que los archivos no se eliminen al detener el docker. 
-e [variable_entorno]=[valor]
 Modifica una variable de entorno (pej. PUID). 
-h [hostname]
 Especifica el hostname que tendrá el docker internamente. 
--name [nuevo_nombre]
 Asigna un nombre para poder identificar el docker. 
--restart unless-stopped
 Indica que se quiere ejecutar el docker persistentemente hasta que se detenga manualmente.

Limitación de recursos:

--cpus [cantidad_CPU]
 Limita los núcleos de la CPU que el docker puede utilizar como máximo (número decimal). 
-m [cantidad_RAM][unidad]
--memory [cantidad_RAM][unidad]
 Ambos parámetros realizan la misma función:
Limita la cantidad de RAM que el docker puede utilizar como máximo. Ejemplos: "512M" (MiB), "1G" (GiB).

Abrir una terminal al ejecutar el docker:

docker run -it [docker] [bash/sh]
 Para que al ejecutar el docker se abra una terminal se debe especificar el tipo de terminal: bash o sh. Para abrir la terminal en un docker que ya se está ejecutando, mire la sección "Abrir una terminal en un docker iniciado".

Redirección de puertos:

-p [puerto_local]:[puerto_docker]
 Se redirecciona el puerto [puerto_local] del host hacia el puerto [puerto_docker] del docker. 
-p [ip_local]:[puerto_local]:[puerto_docker]
 También se puede especificar la IP del sistema local del host.
Se puede redireccionar varios puertos a la vez, para ello hay que repetir el parámetro -p por cada puerto a redireccionar.

Modo de red:

Modo bridge: Por defecto el docker está en el modo de red bridge.
Tiene IP propia (a partir de la red creada por docker) y permite usar mapeo de puertos. El servidor DNS será el mismo servidor que utiliza el host. 
--network host
 Modo host: Con este parámetro el docker no tendrá IP ni mapeo de puertos, solo será un proceso del host.

Otras configuraciones de red:

--dns=[ip_servidor_dns]
 Con este parámetro se indica manualmente el servidor DNS para el docker. Para añadir un servidor secundario se debe duplicar este parámetro. 
--add-host=[dominio]:[ip]
 Con este parámetro se indica una nuevo registro DNS interno en el fichero /etc/hosts. Para añadir otro registro se debe duplicar este parámetro.

Nota - cualquiera de estas opciones se puede modificar más tarde mediante el siguiente comando:

docker update [parámetros] [docker]

Listar los dockers

Para ver los dockers en ejecución:

docker ps

Ver todos los dockers en ejecución y detenidos:

docker ps -a

Los 2 comandos anteriores muestran el ID, nombre, tiempo de ejecución y tiempo de creación de cada docker.

Gestionar la ejecución de un docker

Iniciar un docker:

docker start [docker]

Detener un docker:

docker stop [docker]

Pausar o reanudar un docker:

docker pause [docker]
docker unpause [docker]

Eliminar un docker

Para eliminar un docker primero se debe detener manualmente:

docker stop [docker]
docker rm [docker]

O también se puede forzar la eliminación sin necesidad de detenerlo manualmente:

docker rm -f [docker]

Copiar archivos entre el host y el docker

Cómo copiar archivos internos del docker al host:

docker cp [docker]:[ruta_en_docker] [ruta_en_sistema_local]

[docker]:____: Nombre del docker específico que contiene los archivos a copiar.

____:[ruta_en_docker]: Ruta local del docker que contiene los archivo/s a copiar.

[ruta_en_sistema_local]: Ruta local del host donde se copiarán los archivos.

Copiar archivos del host al interior del docker:

docker cp [ruta_en_sistema_local] [docker]:[ruta_en_docker]

[ruta_en_sistema_local]: Ruta local del host que contiene los archivo/s a copiar.

[docker]:____: Nombre del docker específico al que se copiarán los archivos.

____:[ruta_en_docker]: Ruta local del docker donde se copiarán los archivos.

Abrir una terminal en un docker iniciado

docker exec -it [docker] [bash/sh]

-i: Modo interactivo.
-t: Proporciona una interfaz de línea de comandos.
[docker]: El identificador de docker al que se quiere acceder.
[bash/sh]: Abre una sesión de bash o shell.

Volúmenes

Ver los volúmenes de todos los dockers:

docker volume ls

Crear un nuevo volumen:

docker volume create [nombre_volumen]

Eliminar un volumen existente:

docker volume rm [nombre_volumen]

Crear un volumen en el host donde se guardarán los datos del docker:

docker run --mount type=volume,src=[nombre_volumen],dst=[ruta_en_docker] [docker]

Todos lo datos que hayan en src se cargarán en dst.

Redes

Configuración de una red

Ver las redes y de que tipos son para cada docker:

docker network ls

Modificar redes

Crear una red:

docker network create --driver (tipo_red) --subnet (ip_red/máscara) --gateway (gateway) [nombre_red]

--driver, --subnet y --gateway son opcionales. Creará una interfaz en el host.

--driver: Es el modo de red a seleccionar como bridge, none, host, ..

Eliminar una red tipo bridge:

docker network rm [nombre_red]

Cambiar un docker existente a la nueva red:

docker run --network [nombre_red] [docker]

Ejemplos

Docker "httpd"

Añadir una página .html:

docker run -p 80:80 -p 443:443 -d httpd
docker exec -it [docker] [bash/sh]
apt update
apt install nano

./htdocs/index.html: Editar el archivo para cambiar la página default.

Hay que acceder a la siguiente URL http://{Tu_IP}:{puerto}, siendo el puerto el que redirige al docker (especificado al hacer docker run).

Docker "heimdall"

Sirve para organizar aplicaciones web en un solo lugar. Se accede mediante la URL http://localhost:[puerto]:

docker run --name heimdall -e PUID=1000 -e PGID=1000 -e TZ=america/new_york -p 9998:80 -p 9997:443 -v /home/usuario/Descargas/docker_adr:/config --restart unless-stopped linuxserver/heimdall
