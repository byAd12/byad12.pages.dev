ANSIBLE-PLAYBOOK

Automatizar tareas mediante SSH

none

Instalación

apt-get update
apt-get install -y software-properties-common
add-apt-repository --yes --update ppa:ansible/ansible
apt-get install -y ansible

Ejecutar una tarea

ansible-playbook -i [HOST_FILE] -f [NUM] [TASK].yml

TASK.yml: Fichero que se crea para especificar una tarea.

-f NUM: Especificamos cuántas tareas ejecutará simultáneamente.

-i HOST_FILE: Añadimos en la ruta de ejcución un fichero con un nombre entre [ ] y debajo una lista de nodos en los que ejecutar la tarea, separándolos con saltos de línea:

[class1]
10.200.0.1
10.200.0.2

[class2]
nodo.dominio.tld
...

Verificar la conectividad en varios equipos

ansible [HOST] -i [HOST_FILE] -f -m ping

HOST: Especificamos a que hosts del fichero verificar. Puede ser simplemente all ejecutándolo en todos los nodos o, si hay varios [ ], permite excluir grupos con all:!nombre_grupo_excluir. Además se puede poner el nombre del grupo solamente.

-i HOST_FILE: Añadimos en la ruta de ejcución un fichero con un nombre entre [ ] y debajo una lista de nodos en los que ejecutar la tarea, separándolos con saltos de línea.

-m ping: Hace un ping.

Creación de un fichero .yml

---
- name: Descripción de la tarea
  hosts: all
  become: yes

  tasks:
    - name: Nombre de la tarea
      apt:
        name: nginx
        state: present

    - name: Nombre de la tarea
      copy:
        src: ruta
        dest: ruta
        owner: usuario
        group: grupo
        mode: 'permisos'

PSSH

Paralell-SSH


Instalación

apt-get update
apt-get install -y pssh

Ejecución de comandos simultáneamente

Con esto se puede a parte verificar si una serie de equipos están disponibles ejecutando un comando como "hostname; whoami".

parallel-ssh -h [HOST_FILE] -l [USER] [COMANDO]

USER: Usuario al que conectarse.
COMANDO: Comando a ejecutar remotamente.
-h HOST_FILE: Fichero donde se especificarán mediante saltos de líneas a qué dispositivos copiar el fichero. Formato de ejemplo: 

10.200.0.1
10.200.0.2
...

Parallel-Rsync

Automatizar la copia ficheros


Instalación

apt-get update
apt-get install -y pssh

Enviar un fichero a varios hosts simultáneamente

parallel-scp -h [HOST_FILE] [FILE_SRC] [FILE_DST]

FILE_SRC: Fichero local a copiar en los hosts.
FILE_DST: Ruta de cada equipo destino en la que se copiará el fichero.
-h HOST_FILE: Fichero donde se especificarán mediante saltos de líneas a qué dispositivos copiar el fichero. Formato de ejemplo: 

10.200.0.1
10.200.0.2
...

PRSYNC

Paralell-SCP


Instalación

apt-get update
apt-get install -y pssh

Sincronizar ficheros a varios hosts simultáneamente

Solo se copian los ficheros nuevos o modificados, lo que hace más rápida que copiar todo cada vez.

parallel-rsync -r -p [NUM] -h [HOST_FILE] -l [USER] [FILE_SRC] [FILE_DST]

-r: Copiar recursivamente ficheros y carpetas.
-p NUM: Número de nodos en los que se sincronizará simultáneamente.
USER: Usuario SSH para conectarse a los hosts.
FILE_SRC: Fichero o carpeta local a copiar en los hosts.
FILE_DST: Ruta remota en cada host donde se copiará el fichero.
-h HOST_FILE: Fichero que contiene la lista de hosts (uno por línea), ejemplo: 

10.200.0.1
10.200.0.2
...
