VSFTPD

Servidor FTP en Linux

none

Instalación

Hay que instalar el servicio correspondiente en el servidor:

apt-get update
apt-get install -y vsftpd

Al instalarlo se crea un usuario ftp automáticamente, que se incluye en el grupo ftp.

También crea el directorio /srv/ftp, que su propietario es root y su grupo ftp. Sirve como directorio para los usuarios anónimos.

Comprobación

Hay que comprobar que el usuario y grupo llamados ftp existen y que el directorio home del usuario es /srv/ftp:

cat /etc/passwd | grep ftp
cat /etc/group | grep ftp
ls /srv/ftp

Ficheros importantes

Algunos de los siguientes ficheros pueden no estar creados por defecto, en ese caso deberían crearse si se necesitan:

/etc/vsftpd.conf
 Fichero de configuración 
/etc/ftpusers
 Lista de usuarios del sistema excluidos paras iniciar sesión 
/etc/vsftpd.user_list
 Lista de usuarios del sistema excluidos paras iniciar sesión, pero también se puede permitir si en la configuración está: userlist_deny=NO 
/etc/vsftpd.chroot_list
 Usuarios que no están enjaulados si lo siguiente está en la configuración:
chroot_local_user=YES, chroot_list_enable=YES,
chroot_list_file=[ruta] 
/var/log/vsftpd.log
 Para ver los registros de accesos al servidor

Servicio

Iniciar el servidor:

service vsftpd start

Comprobar el estado del servidor:

service vsftpd status

Directivas de: /etc/vsftpd.conf

Activar los usuario anónimos ("ftp" o "anonymous"). Su carpeta home será /srv/ftp, de solo lectura:

anonymous_enable=YES

Permite la conexión con usuarios del sistema. Su directorio personal será el mismo directorio que tenga en el sistema operativo. Por defecto no están enjaulados: 

local_enable=YES

Permitir escritura:

write_enable=YES

Mensaje de bienvenida:

ftpd_banner="Mensaje con espacios"

Enjaular Usuarios

Enjaular a todos los usuarios locales - /etc/vsftpd.conf:

chroot_local_user=YES

Enjaular a un usuario local específico - /etc/vsftpd.conf:

chroot_local_user=NO
allow_writeable_chroot=YES
chroot_list_enable=YES
chroot_list_file=/etc/vsftpd.chroot_list

Lista de usuarios a enjaular - /etc/vsftpd.chroot_list:

Nombre_usuario_1
Nombre_usuario_2
...

Práctica de ejemplo

1. Meter 3 ficheros en /srv/ftp.

2. Crear una conexión al servidor con el usuario "ftp" y descargar un fichero al escritorio local.

ftp [IP]
get [Nombre_fichero] /home/[Nombre_usuario]/Escritorio

3. Crear una conexión al servidor con un nuevo usuario del sistema y comprobar:

  • Que me deja iniciar sesión.
  • Que puedo subir un fichero al servidor con el siguiente comando: 
    put [Nombre_fichero]
  • Que puedo subir un fichero al escritorio del compañero: 
    put [Nombre_fichero] /home/[Usuario_compañero]/Escritorio

    El usuario debe tener permisos en la carpeta de destino.

Como conectarse con FTP

Con el siguiente comando se puede crear una conexión FTP al sistema remoto:

ftp [IP_servidor] (Puerto)

Para autentificarse, el sistema pedirá un usuario y contraseña.

Comandos más importantes para FTP

ls
 Listar el contenido del directorio. 
cd
 Cambiar de directorio. 
!cd
 Cambiar de directorio del sistema local (no el servidor). 
get
 Descargar un fichero del servidor. 
put
 Enviar un fichero al servidor. 
pwd
 Ver directorio actual. 
rm
 Eliminar un fichero. 
!ls
 Listar ficheros del sistema local (no el servidor). 
mkdir
 Crear una carpeta. 
!mkdir
 Crear una carpeta en el sistema local (no el servidor). 
bye
 Cerrar una conexión FTP. 
?
 Todos los comandos disponibles.
