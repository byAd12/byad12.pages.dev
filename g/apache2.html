Apache2

Servidor HTTP y HTTPS en Linux

none

Instalación

Instalaremos el servicio correspondiente en el servidor:

apt-get update
apt-get install -y apache2 apache2-utils

Permitir en el firewall los puertos que se vayan a utilizar:

ufw allow [Puerto]/[Protocolo]

Archivo de configuración de un sitio virtual

Normalmente los archivos de configuración de sitios virtuales se almacenan en la carpeta /etc/apache2/sites-available/.
Su sintaxis completa es la siguiente: 

<VirtualHost *:[puerto]>

        [poner aquí los parámetros]

</VirtualHost>
Parámetros disponibles
La etiqueta VirtualHost crea un nuevo sitio virtual disponible disponible desde todas sus IPs - * y el puerto especificado - puerto. 
ServerName [FQDN_o_IP]
 Nombre del dominio para este sitio virtual. Si no se define, será localhost. 
ServerAdmin [email_administrador]
 Dirección de email del administrador del dominio. 
DocumentRoot [ruta_local]
 Directorio raíz del sitio web, donde deben colocarse las páginas webs que servirá nuestro servidor (pej. /var/www/html). 
ErrorDocument [codigo_error] /[nombre_archivo_error].html
 Página que aparecerá en caso de error según su código (pej. 404). 
ErrorDocument [codigo_error] ["Mensaje"]
 Mensaje que aparecerá en caso de error según su código (pej. 404). 
Alias /Fuera /usr/share/otra
 Permite el acceso a páginas que estén fuera del árbol de directorios. 
Redirect / [url_a_redireccionar]
 Permite la redirección del usuario hacia otra URL diferente. 
LogLevel [nivel]
 Puede ser: debug, info, notice, warn, error, crit, alert, emerg. 
ErrorLog ${APACHE_LOG_DIR}/error.log
 Archivo donde se definen los registros del servicio.

Para activar un sitio virtual se puede hacer de 2 maneras que hacen el mismo proceso:

ln -s /etc/apache2/sites-available/[ruta_local].conf /etc/apache2/sites-enabled
a2ensite [ruta_local].conf

Para que Apache2 esuche por el puerto deseado se debe modificar el archivo /etc/ports.conf y añadir esta línea por cada puerto a escuchar:

Listen [puerto_a_escuchar]

Configuración de directorios

En el archivo /etc/apache2/apache2.conf se pueden definir los permisos a un directorio específico del disco duro del servidor.

Esta configuración también se puede poner directamente dentro de la etiqueta VirtualHost, teniendo mayor prioridad que ponerla en el archivo apache2.conf.

La sintaxis completa de un directorio es la siguiente (no importan los tabuladores ni espacios, solo importan las mayúsculas):

<Directory [ruta_absoluta]>

        [poner aquí los parámetros]

</Directory>
Parámetros disponibles
La etiqueta Directory crea un nuevo directorio indicando la ruta local absoluta donde se almacenarán sus archivos. 
Options FollowSymLinks
 Si no se pone esta opción, los alias no funcionarán. 
AllowOverride None
 Permite el uso de archivos .htaccess: all.
NO permite el uso de archivos .htaccess: None. 
Options Indexes
 Otorga permisos para mostrar el contenido de la carpeta en caso de no haber localizado el recurso solicitado. Si no tiene permiso dará un error si no llega a localizar el recurso. 
DirectoryIndex [nombre_archivo].html ([nombre_archivo].htm ...)
 Se definen los archivos por defecto que abrirá el servidor en caso de no haberse especificado en la URL. Se intentarán abrir en el orden en que aparecen. Si no se puede abrir ninguno y si la opción Indexes está definida mostrará el directorio principal, si no enseñará un error.

En caso de no definir el parámetro DirectoryIndex, los archivos por defecto se configuran en: /etc/apache2/mods-enabled/dir.conf.

Como configurar un directorio privado

1. En el archivo /etc/apache2/apache2.conf definiremos un nuevo directorio con los siguientes parámetros:

<Directory [ruta_local]>

    AuthName "Mensaje - Acceso Privado"
    AuthType Basic
    AuthUserFile [ruta_archivo_credenciales]
    Require user [nombre_usuario_requerido]

</Directory>

2. Crearemos mediante htpasswd un archivo con la contraseña relacionada al usuario:

htpasswd -c [ruta_archivo_credenciales] [nombre_usuario]

Solo se debe poner el parámetro -c para crear el archivo. Se debe quitar para añadir más usuarios en el archivo.

3. Se debe crear la carpeta definida en <Directory>:

mkdir [ruta_local_directorio]

4. Reiniciar el servicio de Apache2:

systemctl reload apache2

Archivos .htaccess

Sirve para poder dar directivas desde un archivo ubicado en el directorio donde se de permisos.

En /etc/apache2/apache2.conf indicaremos en el directorio deseado que permita el uso de archivos .htaccess:

<Directory [ruta_local]>
    AllowOverride all
</Directory>

En la ruta donde está el directorio crearemos un archivo .htaccess, siendo el archivo por defecto en el que se van a buscar las directivas.

Dentro de este archivo .htaccess se pueden poner todas las directivas que se añadirian normalmente dentro de la etiqueta de <Directory>.

Usar HTTPS con SSL

1. Hay que crear un certificado SSL autofirmado con el siguiente comando:

cd /var/www/html
openssl req -x509 -sha256 -newkey rsa:2048 -keyout certificate.key -out certificate.crt -days 1024 -nodes

2. En /etc/apache2/ports.conf se debe configurar que el servidor escuche el puerto 443 (https):

Listen 443

3. Hay que activar el módulo SSLEngine (solo una vez):

sudo a2enmod ssl

4. En /etc/apache2/sites-available/ crearemos un archivo .conf con el siguiente contenido:

<VirtualHost *:443>
        ServerName (FQDN_o_IP)
        DocumentRoot /var/www/html
        
        SSLEngine on
        SSLCertificateFile /var/www/html/certificate.crt
        SSLCertificateKeyFile /var/www/html/certificate.key
</VirtualHost>

5. Por último habilitaremos el archivo de configuración:

sudo a2ensite (nombre_archivo).conf
