PHP + Apache2

Hypertext Preprocessor

none

1. Instalación

En el servidor Apache2 instalaremos el servicio correspondiente para PHP:

apt-get update
apt-get install -y php libapache2-mod-php

2. Comprobación

1. Ejecutaremos los siguientes comandos de verificación del servicio PHP:

php -v
 Muestra la versión del servicio PHP instalado en el sistema. 
php -m
 Muestra los módulos PHP instalados en el sistema. 
php --ini
 Muestra la ruta de los archivos de configuración .ini del servicio PHP.

2. Verificaremos que en Apache2 no hay ningún error de configuración:

apache2ctl configtest

3. Por último reiniciaremos el servicio de Apache2:

systemctl restart apache2

3. Creación de archivos PHP

Dentro del directorio del sitio virtual crearemos un archivo con extensión .php y dentro pondremos el código PHP correspondiente:

nano /[Ruta_directorio]/[Nombre_archivo].php

Para acceder al código PHP desde el cliente tendremos que ir a la siguiente URL:

http(s)://[IP_servidor_Apache2](:Puerto)/[Nombre_archivo].php

Sintaxis archivo PHP

Etiqueta principal

La primera etiqueta de un archivo .php tiene la siguiente sintaxis:

<?php (Comando/Variables) ?>

Cómo ejecutar un comando (ver comandos):

<?php
[Comando];
?>

Cómo definir una variable:

<?php
$[Nombre_variable] = [Valor_variable];
?>

El valor de la variable puede ser un valor estático entre comillas, una operación matemática (ver operaciones matemáticas) o una función que devuelva un valor (ver funciones PHP).

Comandos PHP

echo "[Valor]"(,"Valor",...);
 Muestra en el archivo .html resultante el texto que se indique.
Puede haber uno o varios argumentos separados por comas, como por ejemplo: 
$nombre = "byAd12";
echo "Hola ", $nombre, "!";
 
print "[Valor]";
 Muestra en el archivo .html resultante los valores que se indiquen.
Solo puede haber un valor pero este se puede contatenar con variables mediante puntos, como por ejemplo: 
$nombre = "byAd12";
print "Hola " . $nombre . "!";
 También se puede utilizar el comando print con paréntesis: 
print (...);

Operaciones matemáticas

[Valor1] [Tipo_operación] [Valor2]
 En "Tipo_operación" puede ser una suma +, resta -, división /, multiplicación *, obtener el resto de una división % o elevar un número al exponente **. Para aplicar la operación directamente sobre una variable y sobreescribir su valor se debe poner el símbolo igual tras el "Tipo_operación": 
[Nombre_variable] [Tipo_operación]= [Valor_a_sumar]

Funciones PHP

gethostname()
 Devuelve el hostname del servidor PHP. 
date("H:i:s")
 Devuelve la fecha actual en formato "Hora:Minuto:Segundo".
