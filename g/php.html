PHP + Apache2

Hypertext Preprocessor

none

1. Instalación

En el servidor Apache2 hay que instalar el servicio correspondiente para PHP:

apt-get update
apt-get install -y php libapache2-mod-php

2. Comprobación

Comandos de verificación del servicio PHP: 
php -v
 Muestra la versión del servicio PHP instalado en el sistema. 
php -m
 Muestra los módulos PHP instalados en el sistema. 
php --ini
 Muestra la ruta de los ficheros de configuración (.ini) del servicio PHP. 
php -i | grep 'Loaded Configuration File'
 Muestra la ruta del fichero de configuración (.ini) del servicio PHP que está actualmente cargado. 
apache2ctl configtest
 Verifica si hay errores de configuración.

Si no hay errores hay que reiniciar el servicio de Apache2 para aplicar los módulos de PHP:

systemctl restart apache2

3. Creación de ficheros PHP

Dentro del directorio del sitio virtual hay que crear un fichero con extensión .php y dentro hay que poner el código PHP correspondiente:

nano /[Ruta_directorio]/[Nombre_fichero].php

Para acceder al código PHP desde el cliente se debe visitar la siguiente URL en el navegador:

http(s)://[IP_servidor_Apache2](:Puerto)/[Nombre_fichero].php

Sintaxis de ficheros PHP

Etiqueta principal

La primera etiqueta de un fichero .php tiene la siguiente sintaxis:

<?php (Comando/Variables) ?>

Esta etiqueta tiene un inicio (<?) y un cierre (?>) y entre ellos puede haber saltos de líneas y espacios.

Dentro de esta etiqueta se pueden ejecutar uno o varios comandos (ver comandos):

<?php [Comando]; ... ?>

También se pueden definir una o varias variables con el siguiente formato:

<?php $[Nombre_variable] = [Valor_variable]; ... ?>

El valor de la variable puede ser un valor estático (string, number, decimal, bool), una operación matemática (ver operaciones matemáticas) o una función que devuelva un valor (ver funciones PHP).

Para definir los metados de un fichero se utiliza la siguiente función:

<?php header("Content-Type: [Tipo]; charset=utf-8"); ?>

El tipo de contenido puede ser "text/plain" para ficheros de texto plano o "text/html" para ficheros HTML.

Comandos PHP

echo "[Valor]"(,"Valor",...);
 Muestra en el fichero .HTML resultante el texto que se indique.
Puede haber uno o varios argumentos separados por comas, como por ejemplo: 
$nombre = "byAd12";
echo "Hola ", $nombre, "!";
 
print "[Valor]";
 Muestra en el fichero .HTML resultante los valores que se indiquen.
Solo puede haber un valor pero este se puede contatenar con variables mediante puntos, como por ejemplo: 
$nombre = "byAd12";
print "Hola " . $nombre . "!";
 También se puede utilizar el comando print con paréntesis: 
print (...);

Operaciones matemáticas

Sintaxis de una operación matemática:

[Valor1] [Tipo_operación] [Valor2]

Tipo_operación puede ser una suma +, resta -, división /, multiplicación *, obtener el resto de una división % o elevar un número al exponente **.

Para aplicar la operación directamente sobre una variable y sobreescribir su valor se debe poner el símbolo igual tras el símbolo de la operación:

[Nombre_variable] [Tipo_operación]= [Valor_a_sumar]

Llamar a funciones propias de PHP

gethostname()
 Devuelve el hostname del servidor PHP. 
date("H:i:s")
 Devuelve la fecha actual en formato "Hora:Minuto:Segundo".

Operadores PHP

Operador if - si se cumple la condición ejecutará el código entre corchetes:

if (Condición) {
    # Código a ejecutar si la condición se cumple
}

Operador else - ejecutará su código entre corchetes si la condición if no se cumple:

if (Condición) {
    # Código a ejecutar si la condición se cumple
} else {
    # Código a ejecutar si la condición NO se cumple
}

Operador for - ejecutará su código entre corchetes un número determinado de veces:

for (Inicio; Contador; Incremento) {
    # Código a ejecutar
}

Un ejemplo es el siguiente, donde se define una variable i que incrementa de valor cada vez que se finaliza de ejecutar el código (un máximo de 5 veces):

for ($i = 1; $i <= 5; $i++) {
    # Código a ejecutar
}

Funciones PHP

Las funciones permiten ejecutar un código que se ejecutará cada vez que se llame a la función. Sintaxis:

function Nombre_función(Parámetro1, ...) {
    # Código a ejecutar
}

Para llamar a una función se debe usar su nombre y también se le pueden pasar los valores que se necesiten:

Nombre_función(Valores);

Ejemplo:

function saludar($nombre, $edad) {
    echo "Hola, " . $nombre . "! Tienes " . $edad . " años.";
}
saludar("byAd12", 33);

Arrays

Los arrays permiten almacenar un conjunto de valores en una sola variable. Sintaxis:

Nombre_variable = array(Valor1, ...);

Para obtener un valor específico de un array se debe indicar su posición empezando desde el número 0:

$Nombre_variable[Posición]
