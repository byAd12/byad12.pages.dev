Estructura

Primero hay que crear un fichero con extensión .sh y añadir contenido en el. Estructura básica del script: 

#!/bin/bash
# Aquí se añadirán todos los comandos necesarios

Para poder ejecutar el script hay que asignar permisos de ejecución:

chmod +x [Ruta_script].sh

Para ejecutar el script solo hay que indicar la ruta relativa o absoluta del fichero:

./script.sh

Parámetros

Al ejecutar un fichero se le puede pasar varios parámetros separados por espacios como, por ejemplo:

[Ruta_script].sh param1 param2 ...

Dentro del script se puede hacer referencia a estos estos argumentos:

$num: Devuelve el valor de un parámetro según su posición - "num". Valor mínimo: 1. Valor máximo: 9.
$0: Devuelve el nombre del script / función.
$*: Devuelve todos los argumentos separados por espacios.
$#: Devuelve el número total de parámetros que se pasaron al script.

Básico

Como enseñar un texto en pantalla:

echo 'texto'

Como solicitar un valor para guardarlo en una variable nombre_var:

read -p 'texto' nombre_var

El texto será el prompt que solicitará el valor a ingresar.

Como esperar cierto tiempo antes de hacer una acción:

sleep <Segundos>

Como llamar a una variable

Todo lo que esté dentro de " " se interpreta como variables y texto:

echo "$nombre_var"

En este ejemplo devolverá el valor que almacene la variable llamada nombre_var.

En cambio todo lo que se encuentre entre ' ' se interpreta solo como texto:

echo '$nombre_var'

En este ejemplo devolverá literalmente $nombre_var.

Comparadores

Para cadenas de texto: Para números:
Igual a 
valor = valor
 
valor -eq valor
Igual a (comodines) 
valor == valor
No igual a 
valor != valor
 
valor -ne valor
Menor que 
valor < valor
 
valor -lt valor
Mayor que 
valor > valor
 
valor -gt valor
Menor o igual que 
valor -le valor
Mayor o igual que 
valor -ge valor
No es nulo 
-n valor
Es nulo 
-z valor
Para ficheros y carpetas: 
-e ruta
 Si existe un fichero o carpeta 
-r ruta
 Si tiene permisos de lectura 
-w ruta
 Si tiene permisos de escritura 
-x ruta
 Si tiene permisos de ejecución

Condicionales

Estructura básica:

if [ condición1 ]; then
    // Qué hacer si se cumple la condición 1

elif [ condición2 ]; then
    // Qué hacer si se cumple la condición 2

else
    // Qué hacer si no se cumple ninguna condición

fi

Para indicar el final de la condicional hay que utilizar fi.

Si se cumplen ambas condiciones:

if [ condición1 ] && [ condición2 ]; then
    // Qué hacer si se cumple la condición 1 Y la condición 2
fi

Una condición u la otra:

if [ condición1 ] || [ condición2 ]; then
    // Qué hacer si se cumple la condición 1 o la condición 2
fi

Si no se cumple la condición:

if ! [ condición1 ]; then
    // Qué hacer si NO se cumple la condición 1
fi

Función CASE

Esta función permite ejecutar varias acciones dependiendo del valor asignado a una variable:

read -p 'texto' var
case $var in

1)
echo 'El valor es 1'
;;

rojo)
echo 'El valor es rojo'
;;

*)
echo 'Este valor no estaba en ningún _)'
;;

esac

Para indicar el final de la función hay que utilizar esac.

Bucle FOR

Esta función recorre un conjunto de valores separados por espacios hasta llegar al final:

for nombre_var in conjunto; do
    // Contenido
done

Ejemplo donde se imprimen los números del 1 al 5:

for i in 1 2 3 4 5; do
    echo "$i"
done

Función WHILE

Esta función ejecuta su contenido si la condición es verdadera indefinidamente hasta que se pare:

while [ condición ]; do
    // Contenido
done

Función UNTIL

Esta función ejecuta su contenido hasta que la condición sea verdadera:

until [ condición ]; do
    // Contenido
done
