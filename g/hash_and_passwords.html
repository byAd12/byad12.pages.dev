Hash

Calcular hashes de archivos y/o contraseñas

Calcular el hash de un fichero

Hashes MD (Message Digest): 
md5sum [Ruta_fichero]
 Calcula el hash MD5 de un fichero.
Hashes SHA (Secure Hash Algorithm): 
sha1sum [Ruta_fichero]
 Calcula el hash SHA1 de un fichero. 
sha256sum [Ruta_fichero]
 Calcula el hash SHA256 de un fichero. 
sha384sum [Ruta_fichero]
 Calcula el hash SHA384 de un fichero. 
sha512sum [Ruta_fichero]
 Calcula el hash SHA512 de un fichero. 
openssl dgst -sha3-256 [Ruta_fichero]
 Calcula el hash SHA3 de 256 bits de un fichero. 
openssl dgst -sha3-512 [Ruta_fichero]
 Calcula el hash SHA3 de 512 bits de un fichero.

Salted Hashing

El salted hashing es un método para almacenar contraseñas de forma segura añadiendo un valor llamado salt (un texto aleatorio único). Su objetivo es evitar ataques por tablas precalculadas (rainbow tables) y asegurar que dos contraseñas idénticas generen hashes completamente diferentes.

El valor de salt debería ser aleatorio para que, al calcular el hash de una misma contraseña varias veces, den hashes completamente diferentes.

Calcular el hash de una contraseña con Salted Hashing

Con el comando openssh passwd se pueden generar distintos tipos de HASH para contraseñas:

Hashes MD (Message Digest): 
openssh passwd -1 [Contraseña]
 Calcula el hash MD5 de la contraseña. No se debe utilizar al ser poco seguro.
Hashes SHA (Secure Hash Algorithm): 
openssh passwd -5 [Contraseña]
 Calcula el hash SHA256 de la contraseña. Como mínimo se recomienda utilizar este método. 
openssh passwd -6 [Contraseña]
 Calcula el hash SHA512 de la contraseña. Es muy seguro, pero requiere un mayor tiempo de computación.

Cada comando devolverá un hash en el siguiente formato (UNIX):

$[Número_método]$[Salt_utilizado]$[Hash_resultado]

Número_método indica el tipo de hash a utilizar como, por ejemplo: $1 - MD5; $5 - SHA256; $6 - SHA512.

Para configurar manualmente el valor Salt hay que utilizar el parámetro -salt:

openssh passwd -[Número_método] -salt [Salt_a_utilizar] [Contraseña]

Contraseñas

Comandos para romper/averiguar contraseñas

John: Averiguar contraseñas mediante un hash

El comando john (John the Ripper) permite descifrar hashes de contraseñas mediante un ataque por diccionario. Su objetivo es comprobar qué palabra de la lista coincide con el hash almacenado para obtener la clave en texto plano: 

john --wordlist=[Ruta_lista_contraseñas] [Ruta_hash_contraseñas]

Con --wordlist se especifica la ruta al fichero donde se almacenan las contraseñas separadas por saltos de líneas.
Puedes descargar un fichero con las 14,34 millones de contraseñas más usadas en el siguiente enlace: rockyou.txt.

Ruta_hash_contraseñas debe apuntar al fichero que contenga las credenciales. En sistemas UNIX tiene el siguiente formato:

[Nombre_usuario]:$[Número_método]$[Salt_utilizado]$[Hash_resultado]
...

De forma predeterminada, el comando intentará detectar el tipo de hash. Si no lo consigue, se debe forzar el tipo mediante el parámetro --format=....
Algoritmos UNIX más habituales: sha256crypt, sha512crypt, md5crypt.


Tras realizar un ataque por diccionario con john, se puede usar el parámetro --show para ver el resultado y las estadísticas del ataque:

john --show [Ruta_hash_contraseñas]

Ten en cuenta que, si se realiza un mismo escaneo dos veces, la segunda vez solo enseñará el resultado de la primera vez ya que el resultado se guarda localmente en la carpeta ~/.john. Puedes eliminar esta carpeta para volver a realizar el escaneo.

Hydra: Probar inicios de sesión en un servidor remoto

El comando hydra permite probar múltiples contraseñas para poder iniciar sesión con uno o varios usuarios en un servicio de una máquina remota:

hydra [USUARIOs] (CONTRASEÑAs) (OTROS_PARÁMETROS) [OBJETIVO]
Parámetros para indicar los usuarios a comprobar: 
-l [Nombre_usuario]
 Indica el nombre del usuario que se usará para probar todas las contraseñas. 
-L [Fichero_lista_usuarios]
 Indica el fichero donde se almacena una lista de usuarios separados por saltos de línea que se usarán para probar todas las contraseñas.
No se puede indicar ambos parámetros en el mismo comando.
Parámetros para indicar las contraseñas a comprobar: 
-p [Contraseña]
 Indica la contraseña que se probará en cada usuario. 
-P [Fichero_lista_contraseñas]
 Indica el fichero donde se almacena una lista de contraseñas separada por saltos de línea que se probará en cada usuario.
No se puede indicar ambos parámetros en el mismo comando.
Otros parámetros opcionales: 
-t [Número_hilos]
 Indica el número de tareas que se ejecutarán en paralelo.
SSH suele bloquear conexiones a partir de 4 hilos. 
-o [Ruta_fichero_salida]
 Permite guardar las contraseñas que encuentre en un fichero. 
-e s
 Por cada usuario se intentará su propio nombre de usuario como contraseña.
Con este parámetro puedes omitir el uso de -p o -P. 
-vV
 Permite ver en tiempo real las contraseñas que prueba para cada usuario.
Como indicar la máquina objetivo: 
[Protocolo]://[DNS/IP_Servidor]
 Tipos de protocolos:
ssh, telnet, ftp, mysql, postgres, smb, ldap, ...

Hydra: Como obtener una lista de los usuarios en la red

Desde un equipo con acceso a la lista de usuarios de la red habrá que filtrar la salida del comando getent passwd para obtener solo la primera columna, que contiene el nombre de cada usuario de la red y, por último, se ordenan los usuarios para eliminar duplicados:

getent passwd | cut -d: -f1 | sort -u > lista.txt

Una vez se obtenga el fichero lista.txt, ya se puede ejecutar hydra especificando el parámetro -L.
