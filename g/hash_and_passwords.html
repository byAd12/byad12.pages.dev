Calcular el hash de un fichero

md5sum [Ruta_fichero]
 Calcula el hash MD5 de un fichero. 
sha1sum [Ruta_fichero]
 Calcula el hash SHA1 de un fichero. 
sha256sum [Ruta_fichero]
 Calcula el hash SHA256 de un fichero. 
sha384sum [Ruta_fichero]
 Calcula el hash SHA384 de un fichero. 
sha512sum [Ruta_fichero]
 Calcula el hash SHA512 de un fichero. 
openssl dgst -sha3-256 [Ruta_fichero]
 Calcula el hash SHA3 de 256 bits de un fichero. 
openssl dgst -sha3-512 [Ruta_fichero]
 Calcula el hash SHA3 de 512 bits de un fichero.

Salted Hashing

El salted hashing es un método para almacenar contraseñas de forma segura añadiendo un valor llamado salt (un texto aleatorio único). Su objetivo es evitar ataques por tablas precalculadas (rainbow tables) y asegurar que dos contraseñas idénticas generen hashes completamente diferentes. Esquema:

Calcular el hash de una contraseña con salt

Con el comando openssh passwd se pueden generar distintos tipos de HASH para contraseñas:

openssh passwd -1 [Contraseña]
 Calcula el hash MD5 de la contraseña. No se debe utilizar al ser poco seguro. 
openssh passwd -5 [Contraseña]
 Calcula el hash SHA256 de la contraseña. Es el método que se recomienda utilizar como mínimo. 
openssh passwd -6 [Contraseña]
 Calcula el hash SHA512 de la contraseña. Es muy seguro, pero requiere un mayor tiempo de computación.

Cada comando devolverá un hash en el siguiente formato:

$[Número_método]$[Salt_utilizado]$[Hash_resultado]

"Número_método" indica el tipo de hash a utilizar como, por ejemplo: $1 - MD5; $5 - SHA256; $6 - SHA512.
Ya que "Salt_utilizado" es aleatorio, si se calcula el hash de la misma contraseña dos veces no se conseguirá el mismo resultado.

Para configurar manualmente el Salt hay que usar el parámetro -salt:

openssh passwd -[Número_método] -salt [Salt_a_utilizar] [Contraseña]

En este caso si se ejecuta el mismo comando 2 veces si se obtendrá el mismo hash ya que el Salt será el mismo.
Es conveniente no utilizar este parámetro ya que es conveniente que sea aleatorio por seguridad.

John: Averiguar contraseñas mediante un hash

El comando john (John the Ripper) permite descifrar hashes de contraseñas mediante un ataque por diccionario. Su objetivo es comprobar qué palabra de la lista coincide con el hash almacenado para obtener la clave en texto plano: 

john --wordlist=[Ruta_lista_contraseñas] [Ruta_hash_contraseñas]

--wordlist especifica la ruta al fichero donde se almacenan las contraseñas separadas por saltos de líneas.

Puedes obtener un fichero con las 14,34 millones de contraseñas más usadas en el siguiente enlace: rockyou.txt.

Ruta_hash_contraseñas debe apuntar al fichero que contenga las credenciales. En sistemas UNIX tiene el siguiente formato:

[Nombre_usuario]:$[Número_método]$[Salt_utilizado]$[Hash_resultado]
...

De forma predeterminada, el comando intentará detectar el tipo de hash. Si no lo consigue, se debe forzar el tipo mediante el parámetro --format=....
Algoritmos UNIX más habituales: sha256crypt, sha512crypt, md5crypt.

Tras realizar un ataque por diccionario con john, se puede usar el parámetro --show para ver el resultado y las estadísticas del ataque:

john --show [Ruta_hash_contraseñas]

Tras realizar un mismo escaneo 2 veces, la segunda vez solo enseñará el resultado de la primera vez, ya que el resultado se guarda localmente en la carpeta ~/.john. Puedes eliminar esta carpeta para volver a realizar el escaneo.

Hydra: Probar inicios de sesión en un servidor remoto

El comando hydra permite probar múltiples contraseñas para poder iniciar sesión con un usuario en un servicio:

hydra -t [Número_hilos] [-l Nombre_usuario | -L Ruta_fichero_usuario] [-p Contraseña | -P Ruta_fichero_contraseñas] [Protocolo]://[DNS/IP_Servidor]

No hay que indicar el parámetro -l a la vez que -L ni el parámetro -p a la vez que -P.

El parámetro -t indica el número de tareas que se ejecutarán en paralelo. SSH suele bloquear conexiones a partir de 4 hilos.

Tipos de protocolos: ssh, telnet, ftp, mysql, postgres, smb, ldap.
