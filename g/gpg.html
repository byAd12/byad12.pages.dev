GPG

Comando de cifrado

none

Instalación

En el equipo donde se creará la clave GPG hay que instalar el servicio necesario:

apt-get update
apt-get install -y gnupg

Crear una clave pública

Con el siguiente comando se inicia un asistente para crear una nueva clave en el sistema local:

gpg --full-generate-key

Respuestas del asistente para crear una clave:

  1. Seleccionar un tipo de llave: DSA and Elgamal.
  2. Indicar el tamaño de la clave entre 1024 y 3072.
  3. Indicar la duración de la clave. Para que no caduque: 0.
  4. Confirmar que los valores son válidos: y.
  5. Indicar tu nombre.
  6. Indicar la dirección de email asociada a la nueva clave.
  7. Añadir un comentario (opcional).
  8. Confirmar que los valores son válidos: o.

Para exportar la clave pública hay que ejecutar el siguiente comando:

gpg --armor --export [Dirección_email] > [Nombre_fichero].asc

Dirección_email: La dirección de email asociada a la nueva clave.
Nombre_fichero: El nombre de fichero que se usará para exportar la clave.

Importar una clave pública

Con el parámetro --import se indica la ruta local de donde se encuentra la clave pública a importar:

gpg --import [Ruta_clave_pública]

Ver las claves importadas

Para ver las claves importadas en modo básico:

gpg -k

Para ver las claves importadas en modo detallado (-v):

gpg -kv

Eliminar una clave importada

Para eliminar una clave importada se debe indicar el dirección de email o el nombre del propietario de la clave pública:

gpg --delete-key [Nombre_clave_importada]

Cifrar un fichero con una clave simétrica

Con el parámetro -c podremos cifrar un fichero mediante una clave simétrica (passphrase) en 2 formatos de ficheros diferentes.

Para cifrar un fichero en formato .gpg:

gpg -c [Fichero_a_cifrar]

Para cifrar un fichero en formato .asc:

gpg -c -a [Fichero_a_cifrar]

Al ejecutar el comando se abrirá un cuadro de diálogo donde se tendrá que ingresar la clave simétrica 2 veces con motivos de verificación.

Cifrar un fichero con una clave asimétrica

Se utiliza el parámetro -e (--encrypt) para cifrar un archivo junto con el parámetro -r (--recipient) para indicar el nombre de la clave pública del destinatario, que debe estar previamente importada en el equipo:

gpg -a -r [Nombre_clave_pública_destinatario] -e [Fichero_a_cifrar]

Para ver el nombre de la clave pública del destinatario se puede usar el parámetro -k (la clave debe estar previamente importada):

gpg -k

El nombre puede ser la dirección de email o el nombre que se indica en el apartado uid.

Descifrar un fichero con una clave a/simétrica

El parámetro -d permite descifrar un fichero que haya sido cifrado por una clave simétrica o asimétrica:

gpg -d [Fichero_a_descifrar]

Si el fichero fue cifrado con una clave simétrica, solo se solicitará la clave simétrica para descifrar el fichero.
Si el fichero fue cifrado con una clave pública (asimétrica), GPG buscará en el sistema la clave privada correspondiente y solicitará la contraseña para utilizarla.

Firmar un fichero

Primero hay que generar un fichero .asc que sirva como firma:

gpg -sb -a [Fichero_a_firmar]

Este fichero .asc se enviará junto al fichero original para verificar si el fichero original se ha modificado o no.

Para verificar si el fichero se ha modificado hay que indicar la ruta del fichero de firma .asc y la ruta del fichero original:

gpg --verify [Ruta_fichero_firma].asc [Ruta_fichero_original]
