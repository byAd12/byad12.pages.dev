Instalación en el servidor

1. Instalaremos el servicio de PostgreSQL y otras dependencias en el servidor:

apt-get update
apt-get install -y postgresql postgresql-contrib sudo

2. Para verificar que se ha instalado correctamente se debe poder ejecutar el siguiente comando y también ver el estado del servicio:

psql --version
systemctl status postgresql

3. Para que el servicio de PostgreSQL se inicie automáticamente al iniciar el equipo:

systemctl enable --now postgresql

4. Por último reiniciaremos el servicio:

systemctl restart postgresql

Asignar una IP estática en el servidor

En el servidor se puede asignar una IP estática desde la interfaz gráfica o, si es un sistema Ubuntu Server, modificando el siguiente fichero:

nano /etc/netplan/50-cloud-init.yaml

1. Primero se debe realizar una copia de seguridad:

cp /etc/netplan/50-cloud-init.yaml /etc/netplan/50-cloud-init.yaml.backup

2. Luego se debe asignar la siguiente configuración, modificando los valores con la configuración de la red en la que se aloja el servidor:

network:
    version: 2
    ethernets:
        [Interfaz_de_red]
            dhcp4: false
            addresses:
              - [IP_estática/Máscara_CIDR]
            routes:
              - to: default
                via: [IP_default_gateway]
            nameservers:
              addresses:
                - 1.1.1.1
                - 1.0.0.1

3. Probaremos que la configuración sea válida con el siguiente comando:

netplan try

4. Por último hay que aplicar la configuración si el paso 3 no dio ningún error:

netplan apply

Para comprobar que la IP estática se configuró correctamente se puede usar el siguiente comando:

ip a

Instalación en el cliente

1. Instalaremos el servicio de PostgreSQL para clientes:

apt-get update
apt-get install -y postgresql-client

2. Una vez instalado se puede ejecutar el siguiente comando para crear una conexión a una base de datos del servidor:

psql -h [IP_servidor] -p [Puerto_servidor/:5432] -U [Nombre_usuario] -d [Nombre_base_de_datos]

Gestionar la base de datos

Para entrar a la base de datos debemos ejecutar el comando psql con el usuario postgres:

sudo -u postgres psql

Otra manera de ejecutar comandos SQL directamente es:

sudo -u postgres psql -c '[Comando_SQL];'

Para ver según el sistema la versión, nombre del clúster puerto, estado, propietario, ruta de datos y registros se debe usar el comando:

pg_lsclusters

En sistemas Debian y Ubuntu se permite gestionar varias versiones y clústers.
El clúster por defecto se llama main.

Comandos básicos de SQL:

SELECT version();
 Indica la versión del servicio de PostgreSQL instalado en el sistema. 
\l
 Lista todas las bases de datos existentes en el clúster. 
\du
 Lista los roles y usuarios, junto con sus atributos y permisos globales. 
\conninfo
 Muestra la información de la conexión actual con la base de datos. 
\q
 Cierra la sesión y finaliza el comando psql.

Configuraciones del sistema:

SHOW config_file;
 Devuelve la ruta absoluta del archivo principal de configuración. 
SHOW hba_file;
 Devuelve la ruta absoluta del archivo de autenticación de clientes. 
SHOW data_directory;
 Muestra la ruta del directorio de datos del clúster. 
SHOW port;
 Muestra el puerto TCP/IP en el que el servidor está escuchando conexiones entrantes (por defecto suele ser 5432).

Para verificar por cual puerto está escuchando el servicio de PostgreSQL (es lo mismo que la consulta SQL SHOW port;):

ss -ltnp | grep postgres

Permitir conexiones remotas

1. Primero debes copiar la ruta local que indique el comando SHOW hba_file;:

sudo -u postgres psql
SHOW hba_file;
\q

2. Debes editar el archivo que se encuentra en la ruta del paso 1 con nano.

3. Dentro del archivo del paso 2 hay que añadir una nueva línea indicando la dirección de red cuyos equipos tendrán permisos de hacer conexiones remotas:

host all all [Dirección_red/Máscara] scram-sha-256

4. Se debe reiniciar el servicio de PostgreSQL para aplicar los cambios:

systemctl restart postgresql

5. Si el firewall está activado, se debe crear una regla para permitir las conexiones de IPs que estén en el rango de la dirección de red hacia el puerto de PostgreSQL:

ufw allow from [Dirección_red/Máscara] to any port [puerto_postgresql] proto tcp

Creación de usuarios

Para crear un nuevo usuario en la base de datos:

CREATE USER [Nombre_usuario] WITH PASSWORD '[Contraseña_usuario]';

Una vez creado, se puede comprobar que el usuario nuevo aparece en el listado:

\du

Creación de bases de datos

Para crear una nueva base de datos se debe de especificar un usuario propietario:

CREATE DATABASE [nombre_base_datos] OWNER [Nombre_usuario_propietario];

Una vez creado, se puede comprobar que la base de datos aparece en el listado:

\l
