isc-dhcp-server

Servidor DHCP en Linux

none

Instalación

En el servidor hay que instalar el servicio correspondiente:

apt-get update
apt-get install -y isc-dhcp-server

En el firewall hay que permitir el tráfico del puerto 67 - UDP (DHCP):

ufw allow 67

Tras instalar el servicio se deben configurar los siguientes archivos: /etc/default/isc-dhcp-server y /etc/dhcp/dhcpd.conf.

Después de configurar los archivos necesarios hay que reiniciar el servicio:

systemctl restart isc-dhcp-server.service

Comprobación del funcionamiento

Primero miraremos si el servicio está encendido y sin errores:

systemctl start isc-dhcp-server.service
systemctl status isc-dhcp-server.service

Comprobaremos que hay un proceso DHCP ejecutándose:

ps -ef | grep dhcp

Miraremos que esté ejecutándose en su puerto correspondiente:

netstat -uap | grep 67

Comprobaremos que no haya errores del servicio registrados en el sistema:

cat /var/log/syslog

Archivos importantes

/etc/default/isc-dhcp-server
 archivo para indicar la interfaz. 
/etc/dhcp/dhcpd.conf
 archivo de Configuración del servidor. 
/var/log/syslog
 archivo de registro de errores del sistema.

Comandos de DHCP para un cliente Linux

Hacer una petición DHCP-DISCOVER (D.O.R.A.) en el cliente:

dhclient -v

Hacer una petición DHCP-RELEASE en el cliente:

dhclient -v -r

Comandos de administración para el servidor

Se pueden ver todas las direcciones IPs concedidas por el servidor DHCP, además de su tiempo de expiración:

dhcp-lease-list

Archivo de configuración: /etc/default/isc-dhcp-server

A continuación deberemos modificar las siguientes líneas del archivo:

INTERFACESv4=""
INTERFACESv6=""

Y lo modificaremos al siguiente contenido:

INTERFACESv4="[Nombre_interfaz_red]"
#INTERFACESv6=""

INTERFACESv4: Se definen las interfaces de red IPv4 en la que funcionará el servidor.
INTERFACESv6: Si IPv6 no está configurado se debe comentar esta línea.

Usa el siguiente comando para poder ver las interfaces del equipo:

ip a

Archivo de configuración: /etc/dhcp/dhcpd.conf

Las líneas que se presentan a continuación pueden definirse dentro o fuera de una "subnet". Si se definen fuera se aplicarán a todas las subredes que se creen.

Esta configuración permite configurar el tiempo de concesión de una configuración IP a un equipo:

default-lease-time [Segundos];
max-lease-time [Segundos];
min-lease-time [Segundos];
Configuración de tiempos de concesión 
default-lease-time [Segundos];
 Tiempo base en segundos de la concesión IP. 
max-lease-time [Segundos];
 Tiempo máximo en segundos de la concesión IP. 
min-lease-time [Segundos];
 Tiempo mínimo en segundos de la concesión IP.

Esta configuración crea una subnet donde se define la configuración IP a conceder y los rangos de IPs a asignar:

subnet [Dirección_de_red] netmask [Máscara_punteada] {
    # Configuración básica
    option routers [IP_default_gateway];

    # Configuración DNS
    option domain-name "[Nombre_dominio]";
    option domain-name-servers [IP_servidor_DNS];

    # Configuración de rangos DHCP
    range [IP_inicial_1] [IP_final_2];
    range [IP_inicial_2] [IP_final_2];
    # ...

    # Configuración de un servicio TFTP para el arranque en red de Debian:
    ## > https://byad12.pages.dev/g/debian_pxe
}
Inicio de la configuración básica 
subnet [DIRECCIÓN_RED] netmask [MÁSCARA] {
 La dirección de red IPv4 y su máscara en formato punteado.
Configuración básica 
option routers [...];
 La dirección IPv4 del enrutador.
Configuración DNS 
option domain-name "[...]";
 El nombre del dominio de la red entre comillas. 
option domain-name-servers [...];
 La(s) dirección(es) IPv4 de lo(s) servidor(es) DNS separados por comas. Estos servidores deben poder resolver el mirror para instalar Debian.
Configuración de rangos 
range [IP_inicial] [IP_final];
 Se define la primera y última dirección IPv4 que se repartirán de ese rango. Gracias a los rangos se pueden excluir ciertas IPs reservadas.

Opcional - también se puede definir una IP estática mediante la dirección MAC del dispositivo:

host [Nombre_dispositivo] {
    hardware ethernet [MAC_dispositivo];
    fixed-address [IP_estática];
}
Parámetros 
host [...] {
 Se le asigna un nombre específico para identificar el dispositivo. 
hardware ethernet [...];
 Es la dirección MAC del dispositivo. ethernet puede ser cambiado. 
fixed-address [...];
 Es la dirección IPv4 estática que se desea conceder al dispositivo.
