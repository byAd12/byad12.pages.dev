POSTFIX

Servidor SMTP

none

1. Instalación

En el servidor donde se enviarán los emails hay que instalar el servicio correspondiente:

apt-get update
apt-get install -y postfix

Respuestas que va a pedir: "Sitio de Internet"; Poner un dominio (real o ficticio).

2. Comprobación

Primero hay que verificar que el servicio postfix se esté ejecutando en el puerto 25:

ps -ef | grep postfix
netstat -ltn | grep 25

También se puede iniciar una conexión mediante telnet desde el propio servidor a su puerto 25:

telnet localhost 25

Dentro de esa conexión se puede enviar el comando HELO, que debería devolver el código 250.

3. Configuración del firewall

En el firewall hay que permitir el tráfico del puerto 25 - TCP (SMTP):

ufw allow 25

Ficheros importantes

/etc/postfix/main.cf
 Fichero de configuración principal 
/etc/postfix/master.cf
 Fichero de configuración del demonio maestro de postfix
Se encarga de interactuar con los procesos para enviar correos

 Fichero para definir alias de correos

Formato del fichero /etc/postfix/main.cf:

parametro=valor: Si una línea empieza con un espacio, continúa a la línea anterior.
$parámetro: Asignar un valor de un parámetro a otro.

ENVIAR CORREOS

Uso de telnet y el comando "mail"

Envío de email con telnet

Para iniciar una conexión telnet hacia un servidor SMTP, como puede ser postfix, se debe indicar la dirección del servidor y su puerto:

telnet [IP/DNS/localhost] [Puerto_servidor_SMTP]

El puerto por defecto de SMTP es el puerto 25 (se debe especificar).

Dentro de la conexión telnet hay que poner los siguientes campos separando cada uno por una línea vacía:

MAIL FROM:[Dirección_remitente]
RCPT TO:[Dirección_destinatario]
DATA
SUBJECT:[Asunto]
[Mensaje a enviar]

Para finalizar de escribir el campo del mensaje hay que dejar una línea en blanco con un punto (.).

QUIT

Envío de email con el comando mail

En el cliente donde se ejecutará el comando hay que instalar el siguiente paquete:

apt-get update
apt-get install -y mailutils

Para enviar un nuevo correo a otro usuario del sistema:

echo "[Cuerpo_del_mensaje]" | mail -s "[Asunto]" (-A [Ruta_del_fichero_a_adjuntar]) [Nombre_usuario_destinatario]

El destinatario puede ser cualquier usuario del sistema.
El parámetro -A (adjuntar un fichero) es opcional.

El destinatario puede ver los correos que ha recibido en la siguiente ruta, indicando su nombre de usuario:

cat /var/mail/[Nombre_usuario]
