CUPS

Common Unix Printing System

none

1. Instalación

En el equipo donde se podrá administrar el servicio hay que instalar los paquetes necesarios:

apt-get update
apt-get install -y cups cups-pdf

2. Comprobación

Para verificar el estado del servicio:

systemctl status cups

También hay que verificar que el servicio esté escuchando en el puerto correspondiente (debería ser el puerto 631): 

lsof -i -P -n | grep cups

3. Limitación de acceso

Para permitir el acceso desde cualquier red al servicio hay que ejecutar el siguiente comando:

cupsctl --remote-any

También se puede limitar el acceso para que solo la red local pueda acceder. Para ello hay que modificar el siguiente fichero:

nano /etc/cups/cupsd.conf

Hay que configurar la sección <Location /> como en el siguiente bloque, pero definiendo el valor Dirección_de_red_local:

<Location />
  Order allow,deny
  Allow localhost
  Allow [Dirección_de_red_local]
</Location>

Para aplicar los cambios hay que reiniciar el servicio:

systemctl restart cups

4. Añadir una impresora CUPS-PDF desde la interfaz gráfica

Desde un navegador web hay que entrar al panel de administración del servicio:

https://[IP_servidor]:631/admin

En la sección de Printers se debe pulsar Add Printer.

  • Seleccionar CUPS-PDF (Virtual PDF Printer) y luego Continue.
  • Definir un nombre a la impresora, una descripción y luego hay que pulsar en Share this printer y Continue.
  • En la sección Make hay que seleccionar el driver Generic, en la sección Model el modelo Generic CUPS-PDF Printer (w/ options) (en) y por último hay que pulsar Add Printer.

Ahora hay que acceder a a la sección de impresoras del panel:

https://[IP_servidor]:631/printers

Al seleccionar la impresora que se ha creado en el paso anterior se podrá ver su cola de impresión.

Después de crear la impresora en el panel web, hay que activarla y permitir trabajos especificando el nombre configurado de la impresora:

cupsenable [Nombre_impresora]
cupsaccept [Nombre_impresora]

Ahora hay que añadir una política al servicio mediante el siguiente fichero:

nano /etc/cups/cupsd.conf

En la sección llamada <Policy default> hay que configurar la siguiente línea:

  JobPrivateValues none

Para aplicar los cambios se debe reiniciar el servicio:

systemctl restart cups

5. Agregar la impresora en los equipos clientes

En un equipo de la red se listarán las impresoras que se detecten:

lpinfo -v

Ahora se debe añadir una impresora al sistema local asignándole un nombre (-p) mediante la IP del equipo (ipp://...) que creó la impresora y el nombre que le asignó a esta (printers/...):

lpadmin -p [Nombre_impresora_local] -E -v ipp://[IP_servidor]:631/printers/[Nombre_impresora] -m everywhere

Una vez se añada la impresora hay que activarla y permitir los trabajos de impresión mediante el nombre configurado en el paso anterior:

cupsenable [Nombre_impresora_local]
cupsaccept [Nombre_impresora_local]

Hay que verificar que la impresora esté en el sistema:

lpstat -p -d

Nota: La impresora puede aparecer inactiva ya que es una impresora virtual sin ningún dispositivo físico conectado.

Para verificar que se pueda imprimir se puede crear un fichero de prueba y enviarlo a la impresora:

echo "Contenido de prueba" > [Fichero_de_prueba]
lp -d <Nombre_Local> [Fichero_de_prueba]

Servidor: En la página de impresoras deberíamos ver los trabajos enviados:

https://[IP_local_servidor]:631/printers

Los PDFs generados se guardarán normalmente en la carpeta del servidor: /var/spool/cups-pdf/.
