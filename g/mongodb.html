MongoDB

Sistema gestor de base de datos NoSQL

none

1. Instalación en el servidor

1. Hay que instalar MongoDB en el servidor:

wget https://repo.mongodb.org/apt/ubuntu/dists/noble/mongodb-org/8.0/multiverse/binary-amd64/mongodb-org-server_8.0.9_amd64.deb
dpkg -i mongodb-org-server_8.0.9_amd64.deb

2. Se debe habilitar e iniciar el servicio mongodb:

systemctl enable --now mongod

3. Ahora hay que instalar el paquete mongosh:

wget https://repo.mongodb.org/apt/ubuntu/dists/noble/mongodb-org/8.0/multiverse/binary-amd64/mongodb-mongosh_2.9.2_amd64.deb
dpkg -i mongodb-mongosh_2.9.2_amd64.deb

Gestionar la base de datos

Para entrar a la base de datos hay que ejecutar el comando mongosh:

mongosh

Otra manera de ejecutar comandos de MongoDB directamente mediante CLI:

mongosh --quiet --eval '[Comando_a_ejecutar]'

Comandos básicos de MongoDB:

Con el comando help se muestra una ayuda de los comandos. 
show dbs
 Lista todas las bases de datos existentes en el clúster. 
use [Nombre_base_datos]
 Se conecta a la base de datos indicada mediante su nombre. 
show collections
 Lista todas las colecciones existentes en la base de datos.
