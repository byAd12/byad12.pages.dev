Mis scripts

A continuación podrás ver mis scripts de gestión públicos.
El uso de "sudo" es para poder ejecutar el script sin problemas de permisos.
Si da fallos, puedes instalar sudo: "apt install -y sudo" y asignarle el grupo sudo a tu usuario.

parrot.sh

Este script es mi archivo de configuración esencial para Parrot Security OS (basado en Linux).

wget https://byad12.pages.dev/scripts/parrot.sh -O parrot.sh; chmod +x ./parrot.sh; ./parrot.sh
